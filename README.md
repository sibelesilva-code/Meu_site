# Mae - projeto front-end

Este projeto vem a entender o bom uso de html e css 
sobre as paginas web ebom uso de programação

## Oque foi feito

-Criaçao de estrutura de HTML em pagina 
-Organizaçao de conteúdo em seções 
- uso de elementos de HTML `herdar`, `nav`,`main`,
`section`,`article` e `table`
-colocamos banner
-fizemos estilizaçao de css
-definimos cores,fontes,espaçamentos e layout visual

## Estrutura do projeto

-`index.html`-estrutura da pagina
-`style.css`-estilo e layout do site
-`imagem/`-imagens usadas do projeto

## tecnologias utilizadas

-HTML
-CSS
